# 咒野 · WILDSPELL

一款 React + Three.js 的俯视角法术生存肉鸽 Demo。春生之庭与凛冬遗迹各有完整的探索、成长、祭坛与 Boss 战流程。美术与声音均由代码生成，不依赖远程模型、图片、字体或音频服务。

## 本地启动

需要 Node.js 20.19+ 或 22.12+。

```powershell
cd "D:\Study\作品分析\saltline_咒语乐团"
npm install
npm run dev
```

打开 http://127.0.0.1:5174 。首次进入会显示操作手记。声音在点击开始后启用。

```powershell
npm run check   # TypeScript 检查
npm run build   # 构建到 dist/
npm run preview # 预览构建产物，http://127.0.0.1:4174
```

## 如何游玩

| 操作                | 功能                                       |
| ------------------- | ------------------------------------------ |
| WASD / 方向键       | 移动；方向相对于屏幕                       |
| 自动施法            | 星火锁定最近敌人，已解锁的其他法术自动释放 |
| 按住鼠标左键        | 将星火引导到鼠标指向的地面                 |
| 空格                | 沿移动方向闪避，短暂无敌，3 秒冷却         |
| Q                   | 奥术脉冲，击退敌人和道具，12 秒冷却        |
| Esc                 | 暂停 / 继续                                |
| 1 / 2 / 3           | 升级时选择对应强化                         |
| 触控摇杆 / 技能按钮 | 手机和平板上的移动与技能                   |

击败敌人后靠近拾取灵息，升级选择三项随机强化之一。沿石径寻找三座祭坛，在附近停留 5 秒完成唤醒；祭坛提供治疗与灵息，同时吸引一波敌人。三座祭坛全部唤醒后季节守望者降临；若探索超过 4 分钟，Boss 会提前出现。击败 Boss 即通关。两关均可从菜单直接进入，春关胜利后也可前往冬关，每次远征重新构筑。

星火、霜环、月轮、陨星、连锁雷鸣与生命绽放可组合。冻结目标受到陨星伤害翻倍，并额外传导一次雷击。Boss 低生命时进入强化阶段，红色地面预警和弹幕需要闪避。

## 技术与目录

- `src/App.tsx`：React 菜单、HUD、升级、结算、指南、设置与触控。
- `src/styles.css`：响应式界面、季节主题与可访问性样式。
- `src/game/engine.ts`：独立于 React 的游戏循环、60 Hz 固定物理步长、战斗与关卡状态机。
- `src/game/world.ts`：春冬场景、地表纹理、实例化植被、风雪、花雨、水面、祭坛和环境道具。
- `src/game/actors.ts`：程序化角色与怪物，以及独立部件动画。
- `src/game/effects.ts`：粒子池、冲击波、闪电与伤害数字。
- `src/game/environment.ts`：程序化环境反射。
- `src/game/audio.ts`：Web Audio 环境音、音乐与动作音效，包含限流和压缩。
- `src/game/config.ts`、`types.ts`：法术/升级配置与共享类型。

Three.js 使用正交俯视相机、PBR 材质、软阴影、接触阴影、泛光和色调映射。Rapier WASM 处理角色/敌人/障碍碰撞、连续碰撞检测、箱罐刚体与冲击力；角色移动约束在水平面，冬季使用更缓的加减速。画质“平衡”关闭额外环境遮蔽与泛光并降低像素密度。

设置和最佳驱散纪录保存在当前浏览器 localStorage。游戏不包含账户、联网合作或服务端存档。

## 开发验收

开发服务器访问 `http://127.0.0.1:5174/?qa=1` 可运行实际游戏状态与 Rapier 物理的集成冒烟检查，结果显示在页面的 `qa-results` 面板。验收入口仅在 Vite 开发模式加载，生产构建不包含测试面板。

玩法参考《咒语旅团》的自动施法生存与法术组合，场景氛围参考 Saltline。角色、美术、法术、地图和音乐为本 Demo 独立的程序化实现。

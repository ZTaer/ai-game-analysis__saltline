## 开始游戏

需要 Node.js 22.12+（本机已用 Node 24 验证）。

```powershell
cd 'D:\Study\作品分析\saltline_愤怒的小鸟'
yarn install
yarn dev
```

打开终端显示的本地地址，通常为 http://127.0.0.1:5173/ 。也可双击 `启动游戏.cmd`。首次安装后，日常启动不需要再次安装依赖。

项目已配置 `.yarnrc.yml` 中的 `nodeLinker: node-modules`。这是为了解决 Windows 上 Yarn 4 PnP 虚拟 ZIP 路径导致 Vite/esbuild 报 `Cannot read file ... .yarn/__virtual__ ...` 的问题。拉取配置后先运行一次 `yarn install`，再运行 `yarn dev`。无需修改全局 Yarn 配置，也无需更改中文项目路径。

仍可使用 `npm install` / `npm run dev`，但建议同一个工作区固定使用一种包管理器。

```sh
yarn test        # 物理行为、关卡稳定性、六关可解性、屏幕适配坐标
yarn build       # TypeScript 检查 + 生产构建，输出 dist/
yarn preview     # 预览生产版本
yarn format      # 格式化源码
```

## 游戏内容

- 打开即显示铺满窗口的游戏主菜单，无网页页眉、页脚或滚动区域。开始行动、选关不会自动请求浏览器全屏；仅点击全屏图标或按 F 时切换全屏，Esc 可退出。
- 主菜单、暂停、选关、音量和结算均叠加在游戏场景内。桌面、超宽屏、手机横屏和竖屏分别适配 HUD；相机缩放后同步换算触控与鼠标坐标。手机竖屏时将完整游戏界面旋转为横屏布局，横放手机后自动恢复自然横屏；旋转显示不请求浏览器全屏。触控位置经过逆旋转换算，保持发射方向准确。
- 六个手工设计的关卡，逐关解锁，最佳得分和星级保存在浏览器 localStorage。
- 红怒：标准撞击。疾风：飞行中点击或按空格加速。黑火：主动引爆或碰撞后 0.85 秒延时爆炸。
- 木材、玻璃、石材拥有不同密度、摩擦、弹性和破坏强度；头盔绿猪需要更强的撞击。
- 弹道预览、飞行轨迹、裂纹、碎屑、受击闪光、计分浮字与屏幕震动。
- 暂停、重试、选关、星级结算、音量控制、静音、全屏、触控与键盘操作。
- 手绘风 Canvas 场景和角色、Web Audio 合成的发射、材质碰撞、爆炸与结算音效。

| 操作 | 鼠标 / 触屏 | 键盘 |
| --- | --- | --- |
| 瞄准 | 按住小鸟，向后拖动 | 方向键调整拉弓位置 |
| 发射 | 松手 | 空格（未瞄准时使用默认角度） |
| 技能 | 飞行中点击场景或技能按钮 | 空格 |
| 暂停 | 暂停按钮 | P / Esc |
| 重试 | 重试按钮 | R |
| 切换全屏 | 全屏按钮 | F（Esc 可退出） |

消灭绿猪 +5,000 分，破坏积木 +500 分，通关时每只未使用小鸟 +10,000 分。两星与三星分数阈值按关卡配置。进度和分数属于当前浏览器及站点端口。

## 物理与维护说明

Matter.js 负责刚体、重力、摩擦、碰撞、角动量和休眠。模拟固定为 120 Hz，渲染使用 requestAnimationFrame；画面卡顿时限制累计步长，切换页面自动暂停。物理和绘制相互独立，物理测试不需要浏览器。

碰撞伤害依据法线相对速度、撞击体质量及材质系数计算。物体超过破坏阈值后移除刚体并生成视觉碎屑。爆炸按距离施加径向速度和伤害。它是以可玩性为目标的刚体模拟，碎裂采用阈值规则和视觉粒子，未实现连续材料形变或有限元破坏。

修改 `levels.ts` 可增加关卡布局；修改 `MATERIALS` 可调材质；`types.ts` 中 `WORLD` 控制场景尺寸与弹弓参数。调整关卡后运行测试确认开局稳定、可通关。

画面和音频不使用外部素材。Google Fonts 为可选的网络字体，失败时自动回退到系统字体，不影响游戏。浏览器要求首次点击或键盘操作后才可播放音频。全屏功能取决于浏览器支持；手机横屏体验更好。

## 验证

`npm test` 覆盖六关静置稳定性、拉弓限制、实际飞行与碰撞、失败换鸟、爆炸冲量、奖励只发放一次，以及六个关卡的可解性。浏览器另行检查渲染、输入、对话框与响应式布局。

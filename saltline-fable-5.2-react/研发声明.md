# 万我工作室研发声明

项目：Saltline · React 可维护版（`saltline-fable-5.2-react`）。

研发团队：**万我工作室**。

## 项目用途

本项目用于技术研究与学习实践，围绕 React 应用组织、游戏模块设计、程序化场景与音频、生命周期管理和回归验证开展学习与分析。

## 本版本工作范围

万我工作室负责本版本的 React 工程化重构与维护，包括应用与菜单界面整合、游戏模块拆分、配置及启动流程整理、中文代码说明、维护文档和回归验证，以及本版本的持续维护。

页面署名为：**万我工作室 · React 工程化重构与维护**。

## 原作品与第三方说明

本项目基于 `saltline-fable-5.2` 原游戏进行重构。原仓库记载游戏由 Claude Fable 5.2 创建，生成过程由 Felix Rieseberg（Anthropic）设置并分享；完整来源和链接保留在 [README 的“来源与署名”](README.md#来源与署名) 中。

万我工作室的声明对应本版本实际完成的工程化重构和维护工作，不改变原作品的创作署名和来源归属。原始项目目录 `saltline-fable-5.2` 不属于本次声明的添加范围。

React、Three.js 等第三方组件沿用各自的作者署名及许可证。本声明用于说明研发与维护职责，不替代原作品或第三方组件的许可证，也不新增项目授权条款。
